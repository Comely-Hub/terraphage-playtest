# Terraphage playtest builds

Early playtest builds of Terraphage, a factory game about building a drone factory on an asteroid.

**Download:** open [Releases](../../releases/latest) and download the `.zip` under Assets. Unzip it and run `Terraphage.exe` (Windows, 64-bit).

Windows may warn "Windows protected your PC" because the exe isn't signed. Click **More info**, then **Run anyway**.

Full instructions, controls and how to send feedback are in `README_PLAYTEST.txt`, both inside the zip and [here](README.txt).
